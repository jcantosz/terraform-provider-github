# github_actions_organization_fork_pr_workflows (Resource)

Manages whether workflows from fork pull requests can run in private repositories in the provider organization. Destroy resets this setting to false; it does not restore the previous policy.

~> **Destroy changes organization policy:** destroying this resource disables workflows from fork pull requests in private repositories (`run_workflows_from_fork_pull_requests = false`). It does not restore the policy that existed before Terraform managed it. Other fork workflow settings are not managed or sent by this resource.

The provider `owner` must explicitly identify an organization. Only one resource should manage this organization-wide setting. Enterprise policy can restrict the values available to the organization.

## Permissions

Organization administration access is required. See the GitHub REST API documentation for [getting](https://docs.github.com/en/rest/actions/permissions#get-private-repo-fork-pr-workflows-settings-for-an-organization) and [updating](https://docs.github.com/en/rest/actions/permissions#set-private-repo-fork-pr-workflows-settings-for-an-organization) private repository fork PR workflow settings for supported authentication methods, token scopes, fine-grained organization permissions, and plan availability.

## Example Usage

```terraform
# Uses the organization configured as the provider owner.
# Destroy disables fork PR workflows in private repositories.
resource "github_actions_organization_fork_pr_workflows" "example" {
  run_workflows_from_fork_pull_requests = false
}
```
