# github_organization_secret_scanning_custom_pattern (Resource)

Manages a single secret scanning custom pattern in the provider organization, not its configuration policy.

The provider `owner` must explicitly identify an organization with secret scanning custom patterns available. Each resource manages exactly one pattern, even though creation and deletion use bulk endpoints. Other patterns and the organization's pattern configuration policy are not managed.

GitHub does not support renaming a pattern through this API, so changing `name` replaces it. Publication (`state`) and `push_protection_enabled` are read-only: publishing or enabling push protection must be performed outside this resource. Pattern creation does not automatically publish the pattern.

Patterns use [GitHub's supported Hyperscan syntax](https://docs.github.com/en/code-security/reference/secret-security/custom-patterns), not Go's RE2 engine. GitHub validates regular expression syntax. When delimiters are omitted on creation, GitHub chooses defaults and Terraform records them. Removing an explicitly configured delimiter retains its current server value; set a non-empty delimiter expression explicitly to change it. Empty delimiter strings follow SDKv2's unset semantics for optional/computed strings. Set `must_match = []` or `must_not_match = []` to clear requirements.

Updates and deletion refresh the pattern's concurrency token immediately before writing. A concurrent change after that refresh produces a version conflict; refresh and retry rather than blindly retrying a stale write.

~> **Destroy affects associated alerts.** The default `post_delete_action = "resolve_alerts"` resolves alerts while preserving their history. Setting `"delete_alerts"` permanently deletes associated alerts. This argument is local deletion behavior, is not read from GitHub, and defaults to `"resolve_alerts"` on import.

## Permissions

Use credentials authorized to manage organization secret scanning custom patterns. Classic personal access tokens require `write:org` for writes. See the REST API documentation for supported authentication, permissions, availability, and endpoint details: [list](https://docs.github.com/en/rest/secret-scanning/custom-patterns#list-organization-custom-patterns), [create](https://docs.github.com/en/rest/secret-scanning/custom-patterns#bulk-create-organization-custom-patterns), [update](https://docs.github.com/en/rest/secret-scanning/custom-patterns#update-an-organization-custom-pattern), and [delete](https://docs.github.com/en/rest/secret-scanning/custom-patterns#bulk-delete-organization-custom-patterns).

## Example Usage

```terraform
# The provider owner must explicitly identify the organization.
# Publication and push protection are managed outside this resource.
resource "github_organization_secret_scanning_custom_pattern" "example" {
  name               = "Internal service token"
  pattern            = "internal_service_[0-9A-Za-z]{32}"
  start_delimiter    = "\\A|[^0-9A-Za-z]"
  end_delimiter      = "\\z|[^0-9A-Za-z]"
  must_match         = ["[0-9]"]
  must_not_match     = ["internal_service_0{32}"]
  post_delete_action = "resolve_alerts"
}
```

## Schema

### Required

- `name` (String) Name of the custom pattern. Renaming requires replacement.
- `pattern` (String) Secret format regular expression using GitHub's Hyperscan syntax. Syntax is validated by GitHub, not Go's RE2 engine.

### Optional

- `end_delimiter` (String) Regular expression following the secret. Omission on creation uses GitHub's server default.
- `must_match` (List of String) Additional regular expressions the secret must match. An empty list clears all requirements.
- `must_not_match` (List of String) Additional regular expressions the secret must not match. An empty list clears all exclusions.
- `post_delete_action` (String) Action for associated alerts on destroy: resolve_alerts preserves alert history (default); delete_alerts permanently deletes alerts. This is local deletion behavior, not a remote pattern attribute.
- `start_delimiter` (String) Regular expression preceding the secret. Omission on creation uses GitHub's server default.

### Read-Only

- `custom_pattern_version` (String) Server concurrency token, refreshed before updates and deletion.
- `id` (String) The ID of this resource.
- `push_protection_enabled` (Boolean) Push protection status reported by GitHub. This API does not manage push protection.
- `slug` (String) Server-generated URL-friendly pattern identifier.
- `state` (String) Publication state reported by GitHub. This API does not manage publication.

## Import

Import using `<organization>:<numeric pattern ID>`. The organization must match the provider `owner` (case-insensitively). Terraform finds the ID across all pages, including unpublished patterns; pattern names are not import identifiers.

```shell
# Organization must match the provider owner; 42 is the numeric custom pattern ID.
terraform import github_organization_secret_scanning_custom_pattern.example my-organization:42
```
