# github_organization_secret_scanning_pattern_configuration (Resource)

Manages the organization push protection override for one provider or custom secret scanning pattern. The organization is selected by the provider's `owner`. Use one resource per pattern; unrelated patterns are not modified.

Find `token_type` identifiers using the [organization pattern configurations API](https://docs.github.com/en/rest/secret-scanning/push-protection#list-organization-pattern-configurations). A custom pattern must already exist and be available in that API. Creating a custom pattern does not publish it.

See the [update endpoint documentation](https://docs.github.com/en/rest/secret-scanning/push-protection#update-organization-pattern-configurations) for authentication and permission requirements. Organization overrides do not bypass enterprise policy.

~> **Destroy behavior:** Destroying this resource resets a provider pattern to `not-set` (inherit its default), or disables push protection for a custom pattern. It does not delete the pattern or its alerts. This can reduce protection; use `lifecycle { prevent_destroy = true }` when resets must be prevented.

Configuration versions are fetched before each write. Conflicts caused by parallel pattern updates are retried with a fresh version.

## Example Usage

```terraform
resource "github_organization_secret_scanning_pattern_configuration" "provider_pattern" {
  pattern_type            = "provider"
  token_type              = "GITHUB_PERSONAL_ACCESS_TOKEN"
  push_protection_setting = "enabled"
}

resource "github_organization_secret_scanning_pattern_configuration" "custom_pattern" {
  pattern_type            = "custom"
  token_type              = "cp_2"
  push_protection_setting = "enabled"
}
```

## Schema

### Required

- `pattern_type` (String) The pattern category: 'provider' or 'custom'.
- `push_protection_setting` (String) The organization override: 'enabled' or 'disabled'. Provider patterns also support 'not-set' to inherit the default.
- `token_type` (String) The token_type identifier returned by the organization pattern configurations API, such as 'GITHUB_PERSONAL_ACCESS_TOKEN' or 'cp_2'. This is not the pattern display name.

### Read-Only

- `id` (String) The ID of this resource.
